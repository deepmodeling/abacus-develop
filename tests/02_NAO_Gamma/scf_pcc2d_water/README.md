Standalone vacuum PCC 2D regression. Compare total energy, ionic forces
and E_pcc against a two-rank reference with one OpenMP thread. The PW case
checks a charged periodic layer with open axis 2; the LCAO case checks a
neutral water layer with open axis 1. Analytic sheet/dipole, normal-force and
electronic-potential derivative tests provide independent kernel references.
The saved original PCC executable was also used for numerical comparison.
