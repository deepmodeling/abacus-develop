Vacuum PCC 2D regression for a charged H3O periodic layer with
`assume_isolated pcc_2d` and open axis 2 (`pcc_2d_axis 2`).

The integration harness compares total energy, ionic force magnitudes and `E_pcc`
(in eV). References use the repository pseudopotentials, `scf_thr 1e-12`,
two MPI ranks and one OpenMP thread per rank.
