# DeltaSpin nspin=2 磁约束方案：精确数据采样能力评估

## 评估背景

目标：对磁性体系大规模标注目标磁构型的能量和力。要求约束是精确的——计算结果对应目标磁构型本身，而非近似构型。

评估分两个约束策略：
1. **方向 + 大小约束**：Mz 精确收敛到目标值
2. **仅约束方向**：Mz 的符号（方向）保持，大小由电子结构自洽决定

---

## 方案 A：标准约束（sc_direction_only = false）

BFGS 优化 lambda_z，使 Mz 收敛到 target_Mz。约束收敛判据为 `|Mz - target_Mz| < sc_thr`。

### 方向 + 大小约束：✅ 可实现

BFGS 迭代调整 lambda_z 直到磁矩误差低于 sc_thr。设 sc_thr = 1e-6 时，每原子磁矩偏差 < 1e-6 μB，对应能量偏差 λ·ΔMz ≈ 1e-6 eV 量级，满足数据采样精度需求。

约束对总能量的贡献为 `ΔE = Σ λ_i (Mz_i - Mz_target_i)`。当约束精确满足时，ΔE ≈ 0，计算所得总能即为目标磁构型下的 DFT 能量。力包含约束力项，对应目标磁构型下的 Hellmann-Feynman 力。

**推荐参数：**

```
sc_mag_switch      1
sc_direction_only  0
sc_scf_thr_mode    immediate     # 尽早启动优化，避免前期浪费
sc_thr             1e-6         # 磁矩收敛精度，按需收紧
nsc                200          # lambda 优化步数上限，确保收敛
```

或使用 threshold 模式（给 SCF 几步热身时间）：

```
sc_scf_thr_mode    threshold
sc_scf_thr         1e-3         # drho 低于此值后开始优化 lambda
sc_thr             1e-6
```

`sc_thr` 是数据采样精度的直接控制参数。1e-4 适合初步筛选，1e-6 适合产线数据，必要时可进一步收紧。

### 仅约束方向：❌ 无法实现

方案 A 约束的是 Mz 的绝对值，不提供"仅约束方向"的机制。无法在约束 Mz 符号的同时让 |Mz| 自由弛豫。

---

## 方案 B：direction_only 两阶段策略

### 方向 + 大小约束：❌ 无法实现

Phase 2 中 lambda 指数衰减，约束力逐渐消失。系统弛豫到自然基态磁矩，而非目标值。最终 Mz ≠ target_Mz。

### 仅约束方向：❌ 无法实现

Phase 2 的 lambda 衰减机制保证"约束力平滑消失"而非"方向保持不变"。算法原理：

1. Phase 1 结束时 Mz ≈ target_Mz（AFM 序已建立，λ ≈ 0.3 eV/μB）
2. Phase 2 起步：λ 开始衰减，每步乘以 0.5^(1/3) ≈ 0.794
3. 约 10 步后 λ 衰减为初始值的 10%，约 20 步后为 1%
4. λ 衰减到一定程度后约束力不足以稳定磁矩方向

**结果取决于交换劈裂强度：**
- 磁矩 > 1 μB 的 3d 原子：交换劈裂强，方向可能稳定——但这是体系的内在稳定性，不是约束的功劳
- 磁矩 < 1 μB 的原子：λ 衰减几分之一后方向就可能翻转

**结论：方案 B 的输出是一个"约束释放后弛豫"的构型，而非"约束方向不变"的构型。** 它提供的是一个近似磁基态搜索的方法，而非能在目标方向上标注精确能量的方法。Phase 2 末态的磁矩方向是否与目标一致，需要逐例事后检查，不存在可调参数使其保证。

---

## 方案 C：常量 lambda（sc_scf_thr_mode = "off"）

lambda 从 STRU 读入，作为常量约束加入哈密顿量，不做 BFGS 优化。

哈密顿量中多了一项 `H_const = λ_z σ_z`，Mz 收敛到 λ_z 与 DFT 势的平衡值，**不等于 target_Mz**（除非 λ_z 恰好取到使 Mz = target_Mz 的值）。

### 方向 + 大小约束：❌ 无法实现

Mz 由 SCF 自洽决定，偏移量依赖于 λ_z 的取值。除非 λ_z 经过精确预计算（本身就需要方案 A 求解），否则 Mz ≠ target_Mz。

### 仅约束方向：⚠️ 弱偏置，非精确约束

小的 λ_z 可以为 Mz 方向提供一个弱偏置，但：
- λ_z 太小：方向可能不稳定
- λ_z 太大：|Mz| 被偏置，偏离自洽值
- 效果依赖 λ_z 的取值，不是参数化的"仅约束方向"方案

---

## 总结

| 约束策略 | 方案 A（标准） | 方案 B（direction_only） | 方案 C（off） |
|---|---|---|---|
| 方向 + 大小 | ✅ 可实现 | ❌ | ❌ |
| 仅约束方向 | ❌ | ❌ | ⚠️ 弱偏置 |

**nspin=2 下能用于精确数据采样的只有方案 A 的方向 + 大小约束。** 仅约束方向的精确采样在 nspin=2 体系下目前没有可行方案。

---

## 仅约束方向的精确采样：nspin=4 替代方案

如果研究问题需要"仅约束方向、大小自由弛豫"的精确数据标注，应使用 nspin=4（非共线）模式。在 nspin=4 下，lambda 有 x、y、z 三个分量，`direction_only` 投影仅移除平行于目标方向的分量，保留横向分量，约束力在横向方向精确存在。

```
nspin              4
noncolin           1
sc_mag_switch      1
sc_direction_only  1
sc_scf_thr_mode    immediate
```

此时 M 的方向被精确约束到目标方向，|M| 由 SCF 自洽决定。能量和力对应的是"方向固定、大小自洽"的构型——这正是数据采样所需。

**代价：** nspin=4 计算量约为 nspin=2 的 2-4 倍（复数波函数 + 更多的自旋通道），但这是获得精确方向约束的唯一途径。
