## 5. 结论

1. **缓存优化有效**：`before_scf` 和 `initialize_psi` 耗时合计减少 **~0.6s/run（-35%）**，这是 `collect_local_pw`、`setupIndGk` 等函数避免重复计算和内存分配的直接收益。
2. **Serial 模式全面提速 17%**：wall time 从 34.7s 降至 28.7s，除缓存收益外，不同 git commit 的基础状态差异也贡献了一部分。
3. **MPI 配置需物理机验证**：WSL2 的 MPI 噪声（基线报告已标注）导致 `mix_np2_omp4` 等配置不可比，这些配置的对比结论需要迁移到物理机 Linux 后重新获取。
4. **所有 54 次运行全部通过**（100% 通过率），功能正确性不受缓存修改影响。
